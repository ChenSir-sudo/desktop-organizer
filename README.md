# 桌面整理（DesktopOrganizer）

<img src="Resources/AppIcon-1024.png" width="120" align="right" alt="应用图标" />

一个只做一件事的 macOS 小工具：**整理框**。

在桌面上摆几个毛玻璃小面板，把文件拖进去归类。

拖进去的文件会从桌面消失，**但路径一个字符都不变** —— git、IDE 工作区、相对引用、
构建缓存全都不受影响。把它从整理框里移除，文件立刻回到桌面原处。

原生 Swift + AppKit/SwiftUI，无第三方依赖，无 Electron。

---

## 安全保证：绝不损坏、绝不丢失你的文件

这是本程序最重要的一条。下面每一条都对应代码里的硬约束，并且有可运行的测试
（`--safetest`，26 项断言）。

### 每个操作到底对文件做了什么

| 你做的事 | 对文件的实际操作 |
| --- | --- |
| 把文件 / 文件夹拖进整理框 | 只设隐藏标志（`UF_HIDDEN`），**路径一个字符都不变** |
| 从框里移除条目 | 撤销隐藏标志 |
| 删除整理框 / 清空整理框 | 撤销隐藏标志 |
| 「按类型归类桌面」 | 建整理框 + 设隐藏标志（不移动文件） |
| 条目右键 → 显示 / 隐藏原文件 | 单独设 / 撤销隐藏标志 |
| 条目右键 → **移到废纸篓…** | 移进废纸篓（**二次确认**，可随时拖回来） |
| 把条目拖到**框内文件夹图标**上 | ⚠️ **真正把文件移进那个文件夹**（见下） |
| 把条目拖到框外（**不按 ⌥**） | 只从框里移除条目，**文件不动** |
| 把条目拖到框外（**按住 ⌥**） | 交给访达处理（见下） |

**只有一处会真正移动你的文件：把条目拖到框内的文件夹图标上。** 其余全部只动隐藏标志。

### 硬保证

1. **全程序没有任何绕过废纸篓的删除。** 需要删除时只有
   `FileManager.trashItem` —— 一定进废纸篓，一定可以恢复。
2. **搬移只用内核的 `renamex_np(RENAME_EXCL)`，不用 `FileManager.moveItem`。**
   - 同设备 = 一次原子重命名：**要么完成，要么完全没发生**
   - 不同设备时内核直接返回 `EXDEV`，**永远不可能**退化成「复制 + 删除」——
     这正是之前丢文件的那条路
   - `RENAME_EXCL` 保证目标已存在时失败，**绝不覆盖同名文件**
     （POSIX 的 `rename(2)` 是会覆盖的，所以不能直接用）
3. **移动失败 = 源文件原封不动，条目也不摘。** 没有"复制成功后再删源"的兜底逻辑，
   也不会出现「文件没搬走、条目却没了」。
4. **隐藏只改标志位。** 不改内容、不改位置、不改权限、不改时间戳。
5. **这些路径永远不碰**：程序自身、程序配置目录、你的主目录、桌面根目录。
6. **删除整理框、移除条目、清空 —— 永远不会删除文件**，只解除引用。
7. **先记账、后动文件。** 隐藏一个文件之前，先把「我隐藏了它」记进配置并**确认落盘成功**。
   落盘失败就撤销记录、一个文件都不隐藏 —— 绝不留下「文件被隐藏、却没有任何记录」
   的黑洞（那种状态下程序自己都恢复不了它）。
8. **配置文件不会被写坏或写空**：
   - 读不出来时**锁死写盘**（内存里是空状态，写下去等于毁掉仅存的那份），
     并额外留一份 `config.unreadable-<时间戳>.json`
   - 覆盖前只要会丢信息（盘上框更多 / 隐藏记录更多 / 盘上那份读不出来），
     就先存一份带时间戳的备份
9. **只允许单实例运行。** 两个实例会各持一份内存状态、退出时互相覆盖配置
   （连 `hiddenPaths` 一起丢，导致文件永久隐藏）。第二个实例会自动把已有实例
   叫到前面然后自己退出。


### 隐藏了怎么用 VSCode / 终端打开？

隐藏只影响访达的显示，**不影响任何按路径访问的程序**。三种办法：

1. **右键条目 → 用 VSCode 打开 / 在终端中打开**（程序内置）
2. **终端直接按路径进**
   ```bash
   cd ~/Desktop/TradePilot
   code ~/Desktop/TradePilot
   ```
3. **访达里按 `⌘⇧.`** 临时显示全部隐藏文件，找完再按一次收起

需要长期可见就右键条目 →「显示原文件」，或者到主窗口设置页点「恢复 N 个原文件的显示」。

如果某个文件被你在访达里移走或删掉了，整理框会把它标成「已失效」（图标变暗 + ⚠️），
右键移除即可。

### 只恢复程序自己隐藏的文件

程序在 `hiddenPaths` 里记着**本程序隐藏过哪些路径**，只恢复这些，
不会碰你自己手动隐藏的东西。（它与整理框解耦，所以同一个文件被多个框引用时，
最后一个框移除它才会恢复 —— 不会出现永久隐藏。）

另外还有两道保险：

- 删除整理框 / 清空条目之前会提示将恢复多少个文件
- 设置页里有兜底按钮「恢复 N 个原文件的显示」，随时一键全还原

### 拖到框外：默认什么都不会发生

把条目拖出整理框时，**默认不允许落到应用之外**（这时只从框里移除条目，文件不动）。

如果你确实想让访达接管（比如把文件复制进访达窗口里的某个目录），
**按住 ⌥ 再拖**。放行时也只给 `.copy`，**永远不给 `.move`** ——
最坏情况是目标位置多一份副本，**源文件永远在**。

## 功能

### 主窗口：一个正经的操作页面

![主窗口](docs/screenshots/main.png)

- **整理框页**：所有整理框一览，显示条目数、失效数，可一键隐藏/定位/删除
- **设置页**：新框默认外观、桌面归类、启动行为
- 两页之间是整页滑动切换，不是弹窗
- 有 Dock 图标，点一下就能把窗口叫回来

### 整理框

![整理框](docs/screenshots/box.png)

- **上栏右侧的操作按钮平时隐藏**，鼠标移过去才淡入 —— 平时就是一块干净的玻璃，不打扰
- 齿轮**整页切换到设置页**（窗口尺寸不变），带左右滑动过渡
- **只有双击标题才能改名**，避免拖动或单击误触
- 拖文件进来即归类（**只建引用，不移动文件**）
- **多选**：单击 / ⌘点选 / ⇧范围选，可整批拖走
- 把条目拖到**框内的文件夹图标**上会把文件移进那个文件夹（唯一会移动文件的手势）
- 右键条目可以打开、在访达中显示、复制路径、移除、移到废纸篓
- 背景效果：6 种毛玻璃材质 + 纯色，透明度 10%–100%，圆角 0–36

### 窗口对齐

拖动整理框靠近另一块整理框或屏幕边缘/中线时，会在 8pt 内**吸附**，
并显示一条淡淡的引导线（吸附点还有一个小方块标记）。支持边对边拼接。

**调整大小时同样吸附**：缩放固定左上角，所以右边缘和下边缘会对齐到屏幕
和其它整理框的边/中线，并显示同一套引导线。

## 构建

需要 macOS 14+ 与 Swift 5.10+（命令行工具即可，**不需要完整 Xcode**）。

```bash
cd DesktopOrganizer
./scripts/build-app.sh          # 默认 release
open "dist/桌面整理.app"
```

产物在 `dist/桌面整理.app`。

## 使用

启动后：

1. 出现**主窗口**，列出所有整理框
2. 点右上角「+ 新建」建一个整理框，它会淡入出现在屏幕右上角的空位
3. 把文件拖进整理框
4. 鼠标移到整理框上栏**右侧**，出现 `+` `⚙` `✕` 三个按钮

菜单栏也有一个 `⊞` 图标（可在设置里关掉），提供新建、归类、显示/隐藏等快捷入口。

> **关于配置迁移**：早期原型把整理框绑定到「搬移目标文件夹」。程序升级时会把那个
> 文件夹里已有的内容一次性导入成引用（**只读不改**），之后该字段彻底弃用。
> 现在程序不会再自动搬移任何文件。

## 诊断

不启动界面也能自检：

```bash
APP="dist/桌面整理.app/Contents/MacOS/DesktopOrganizer"
"$APP" --scan       # 只列出桌面会被怎么归类，不动任何文件
"$APP" --selftest   # 断言：加完引用后文件仍在原处；去重；保护规则
"$APP" --snaptest   # 断言：吸附几何（阈值内吸附、阈值外不吸附、引导线）
"$APP" --hidetest   # 单独验证隐藏标志的设/撤两个方向

# 安全测试：验证「不可能损坏或丢失文件」的每一条保证
"$APP" --safetest
"$APP" --safetest /Volumes/某磁盘   # 额外验证「跨宗卷移动被拒绝」
```

`--safetest` 覆盖的保证（26 项断言）：

- 移动成功 ⇒ 目标内容完整、源已不存在
- **移动失败 ⇒ 源文件仍在原位置、内容一字未变**
- **跨宗卷移动被拒绝**，且源文件不动、目标位置零遗留
- 拒绝把文件夹移进它自己
- 桌面 / 配置目录 / 主目录 / 程序自身 一律不碰
- 隐藏 / 取消隐藏只改标志位，内容与位置不变
- 从整理框增删条目、删掉整理框 —— 文件一个都不少、内容不变

开发用的窗口自检：

```bash
DO_DIAG=/tmp/diag.txt      # 窗口几何 / 层级 / 拖拽通道快照
DO_DIAG_PAGE=1             # 顺便把第一个整理框切到设置页
DO_DIAG_MAINSETTINGS=1     # 顺便把主窗口切到设置页
```

```

│   ├── BoxPanel.swift               NSPanel 子类

├── Views/
│   ├── MainView.swift               主窗口：整理框列表

│   ├── HiddenFlag.swift             文件隐藏标志（原位置隐藏/恢复）
│   ├── FileActions.swift            打开/显示/复制路径/移入文件夹/废纸篓
```
